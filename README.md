# 일기장

HTML 파일 하나로 쓰는 일기 앱입니다. 쓴 일기는 내 컴퓨터 폴더에 Markdown(`.md`)으로 저장되고, 그 폴더를 Obsidian에서 열면 일기끼리 연결된 관계도로 볼 수 있습니다.

- 무료, 회원가입 없음
- 일기는 서버로 보내지 않고 내 컴퓨터에만 저장
- 기본 양식: 아침 일기(감사한 일, 오늘 하루를 좋게 하기 위해서), 저녁 일기(굉장한 일, 아쉬운 일), 메모

## 시작하기

컴퓨터의 Chrome이나 Edge를 쓰세요. 다른 브라우저에서는 폴더에 바로 저장되지 않고 파일로 내려받아집니다.

1. 이 저장소에서 `Code` → `Download ZIP`을 누르고 압축을 풉니다.
2. `일기장.html`을 Chrome이나 Edge로 엽니다.
3. 아래쪽 `폴더 고르기`를 눌러 일기를 모아 둘 폴더를 고릅니다.
4. 일기를 쓰고 `저장`을 누르거나 `Ctrl+S`를 누릅니다.
5. Obsidian에서 `Open folder as vault`로 같은 폴더를 엽니다.

터미널을 쓴다면 아래처럼 받을 수 있습니다.

```bash
git clone https://github.com/RIMWOO-0819/woorim-diary.git
```

## AI에게 맡겨서 설치하기

Claude Cowork나 ChatGPT 데스크톱의 로컬 작업 모드처럼 내 폴더와 명령 실행 권한이 있는 환경에서 씁니다. 일반 웹 대화창은 내 컴퓨터에 설치할 수 없습니다.

작업할 폴더를 연결한 뒤 아래 프롬프트를 붙여 넣으세요.

```text
https://github.com/RIMWOO-0819/woorim-diary 의 README를 먼저 읽고, 이 일기장을 연결된 폴더에 내려받아줘.
시작 전에 인터넷, 파일, 명령 실행 권한이 있는지 확인해줘.
끝나면 일기장.html이 실제로 있는지 확인하고 저장 위치를 알려줘.
막히면 어떤 권한이나 단계에서 막혔는지 알려줘.
```

## 내 양식으로 바꾸기

`일기장.html`이 있는 폴더를 AI에게 연결한 뒤 아래 프롬프트의 대괄호를 채워 붙여 넣으세요.

```text
이 폴더의 일기장.html에서 일기 양식을 바꿔줘.

- 아침 질문: [질문들]
- 저녁 질문: [질문들]
- 질문마다 칸 수: [3]
- 아침 인사말: [문장]
- 저녁 인사말: [문장]

코드의 QUESTIONS, TOPICS, COUNT, GREET만 고쳐줘.
- QUESTIONS의 q는 화면에 보이는 질문이고 h는 저장되는 제목이야. h는 짧게 써줘.
- TOPICS는 Obsidian에서 모아 볼 주제 이름이야. 새 질문에 맞게 바꿔줘.
- 이미 쓴 일기가 있으면, 제목이 바뀐 항목은 앱에서 안 보이고 md 파일에는 남는다고 먼저 알려줘.
- 고친 뒤 스크립트 문법 오류가 없는지 확인하고 바꾼 줄을 보고해줘.
```

## 알아두기

- 온라인 AI에게 일기 폴더를 읽히면 일기 내용이 그 서비스로 전송됩니다. 민감한 내용이 있다면 먼저 확인하세요.
- 앱을 처음 쓸 때는 글꼴을 인터넷에서 불러옵니다.
- 일기 파일은 직접 관리해야 합니다. 폴더를 지우면 일기도 지워집니다.
